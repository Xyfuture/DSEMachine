下面是搜索的时候和仿真的时候，可以用到的硬件可以配置参数 

1. system 中芯片的个数
    - int 类型 
2. 单个chip 中 PIM chiplet 的数量
    - int 类型
3. PE - M
    - 单个 PIM chiplet 中，PE 是一个 MxN 的 2d layout，这里是 M 的配置
    - int 类型
4. PE - N
    - 同上, 这里是 N 的配置 
    - int 类型
5. PE bank capacity 
    - 单个 bank 的容量 
    - int 类型
6. PE bank number
    - 一个 PE 的 local banks 有多少
    - int 类型 
7. PE MemoryController number
    - 一个 PE 拥有多少个 Memory Controller
    - 决定了带宽的情况 
    - int 类型 
8. PE Systolic Array - M
    - 一个 PE 内部的脉动阵列布局 MxN 个 MAC 单元，这里是M 的值
    - 采取 output stationary 的逻辑，这里的 M 就是 input tensor 的 batch 维度
    - 如果 input tensor 的 M 维度
    - int 类型 
9. PE Systolic Array - N 
    - 这里是脉动阵列的 N 的值 
    - int 类型
10. PE Systolic Array number
    - 这里是一个 PE 中脉动阵列的数量
    - int 类型
11. PE Systolic Array Frequency 
    - int 类型
    - Unit: MHz
    - 目前考虑将这个设置成固定的 1GHz 
    - 表示脉动阵列中，每个基础的MAC 单元的频率，对整体的运算能力有影响
11. 单个 PIM chiplet 与 IO chiplet 互联的 serdes 的数量
    - int 类型
    - 带宽相关
    - 这个会同步决定 IO chiplet 的serdes 数量

12. 单个Chip 的对外的 serdes 的数量 (C2C 的数量)
    - int 类型
    - 和芯片之间的带宽直接相关
13. IO chiplet 的 buffer 的容量
    - int 类型
    - 暂时没有什么效果，只决定 batch 的可行性 
15. DRAM channel 的参数
    - 含有多个参数
    - 都采用固定值，不进行搜索
    - 主要是 DRAM 的 timming 参数，用于确定单个 DRAM channel 最后的带宽是多少
